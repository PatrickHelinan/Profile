Hydraulic inventory calculator for post-precipitation separation

A screening tool that turns stage durations into nominal hydraulic inventory, V = Q·τ, and compares a candidate separation sequence with chemical-clarification design references. The core block reproduces the prospective analysis in my first-author manuscript; the extensions below it are parametric and use assumptions you supply.

Boundary: separation stage only; upstream precipitation and ageing are excluded. The continuous-flow translation assumes equivalent performance at the same nominal HRT. This is a design-screening estimate, not a validated reactor design.

Formulas, sources and how to check the numbers
  • Equivalent process time: τeq = Σ τi. Continuous-flow translation assumes τHRT,nom = τeq.
  • Nominal inventory: V = Q · τ / 1440, with Q in m³/d and τ in min. At Q = 1000 m³/d and τ = 17 min: 1000 × 17 / 1440 = 11.81 m³.
  • Ratio: Vreference / Vcandidate. Reference stages are treated as sequential and additive.
  • Plan area (extension): A = V / depth; ignores freeboard, walls and hydraulic design.
  • Nanocoagulant make-up (extension): gross = dose × Q / 1000 kg/d; make-up = gross × (1 − reuse fraction). Reuse fraction is a user assumption; my manuscript reports 65.9 % of initial inventory entering Cycle 3 for the silica-coated material under the tested conditions, which is not the same quantity as a per-cycle recovery fraction.
  • Design references: Virginia Administrative Code 9VAC25-790-850 (chemical clarification): reactor-clarifier 30 + 120 min; separate flocculation and settling 20 + 240 min.
  • Self-check: on load, the page recomputes the manuscript case and compares against the published Fig. 5 source values to 1e-9 m³. The same vectors drive the Python test suite.
  • AI use: the layout and script were drafted with AI assistance. Every formula was written out above and the self-check below verifies the output against independently recorded figures.
